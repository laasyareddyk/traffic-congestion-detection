# Traffic Congestion Detection

## Overview
This project detects and classifies vehicles from video
using YOLO and OpenCV.

## Features
- Vehicle detection
- Vehicle counting
- Car, bike, bus and truck classification
- Traffic density estimation
- Congestion analysis

## Technologies
- Python
- YOLO
- OpenCV
- Streamlit
